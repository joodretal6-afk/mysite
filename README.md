# 🧀 منصة الأجبان — بوت + لوحة تحكم كاملة

منصة متكاملة تجمع:
- **بوت فيسبوك ماسنجر ذكي** لـ 9 صفحات (يرد، يفهم الصوت، يميّز الأصناف والأماكن، ويستخرج الطلبات).
- **تخزين ثابت وقوي** عبر SQLite (بديل موثوق عن Cloudflare KV — ما بيخرب الذاكرة).
- **لوحة تحكم عربية (RTL)** بدخول بكلمة سر، تعرض كل الأوردرات مع بحث وفلترة وتصدير **Excel/CSV**.

> ملاحظة: كل منطق البوت الأصلي والمفاتيح محفوظة كما هي داخل `src/bot/` و `src/config.js`.

---

## ⚙️ التشغيل

```bash
# 1) تثبيت الحزم
npm install

# 2) (اختياري) نسخ ملف الإعدادات
cp .env.example .env

# 3) إنشاء مستخدم أدمن للوحة التحكم
npm run create-admin -- admin YOUR_PASSWORD

# 4) تشغيل الخادم
npm start
```

بعدها:
- لوحة التحكم: `http://localhost:3000/admin`
- الويبهوك لفيسبوك: `http://localhost:3000/webhook`
- توكن التحقق (Verify Token): `talebbot` (قابل للتغيير عبر `.env`)

## 🚚 ربط فيسبوك

1. شغّل الخادم على سيرفر له دومين HTTPS (أو استخدم نفق مثل ngrok للتجربة).
2. في إعدادات تطبيق Meta → Webhooks:
   - Callback URL: `https://YOUR_DOMAIN/webhook`
   - Verify Token: `talebbot`
   - فعّل حقول: `messages`, `messaging_optins`.
