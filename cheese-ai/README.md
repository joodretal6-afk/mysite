# 🧀 شيخ الجبنة — Cheese AI

مساعد ذكي مختصّ بالأجبان النابلسية. واجهة دردشة مثل ChatGPT، لكن كل معرفته بالجبنة فقط — يرحّب، يحاور طبيعياً كإنسان، يحاسب، ويصدّر الطلبات.

**مشروع مستقل تماماً** — لا علاقة له بالبوت الأساسي (Facebook Messenger)، وله سيرفره وبياناته ومنفذه الخاص.

## التشغيل
```bash
cd cheese-ai
npm install
npm start          # يعمل على المنفذ 4000 (أو CHEESE_PORT)
```
- الدردشة: `http://localhost:4000/`
- لوحة الإدارة: `http://localhost:4000/admin` (كلمة السر الافتراضية: `admin123` — غيّرها من الإعدادات)

## أول خطوة
افتح **لوحة الإدارة ← الإعدادات** وأدخل **مفتاح API** (Gemini أو OpenAI). بدونه لن يرد البوت.

## لوحة الإدارة (5 صفحات)
1. **المنتجات** — إضافة/تعديل/حذف الأصناف.
2. **الأسعار** — تعديل سريع للأسعار (يتغيّر رد البوت فوراً بدون إعادة تدريب).
3. **الأسئلة والأجوبة** — قاعدة معرفة يستند إليها البوت.
4. **الطلبات** — الطلبات المكتملة تلقائياً من الدردشة، مع الحالة.
5. **الإعدادات** — المفتاح، المزوّد، الموديل، معلومات المتجر، كلمة السر.

## التقنية
- Node.js + Express (بدون قاعدة بيانات ثقيلة — ملفات JSON بسيطة).
- معرفة حيّة (RAG بسيط): الشخصية + المنتجات + الأسعار + الأسئلة تُبنى في كل رسالة من قاعدة البيانات.
- يدعم Gemini و OpenAI (قابل للتبديل من الإعدادات).

## متغيّرات البيئة (اختيارية)
- `CHEESE_PORT` — المنفذ (افتراضي 4000).
- `ADMIN_PASS` — كلمة سر أولية للوحة.
- `DATA_DIR` — مسار حفظ البيانات (افتراضي `./data`).
- `CHEESE_SECRET` — سر توقيع جلسة الإدارة.
